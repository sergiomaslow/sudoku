# 🎮 Sudoku Minimal Futurista (Android APK)

Juego de Sudoku ligero, minimalista y futurista. Se compila como APK de Android automáticamente con GitHub Actions.

## ✨ Características
- Modo claro / oscuro (con memoria)
- 3 dificultades: Fácil, Medio, Difícil
- Responsive para móvil
- 100% offline

## 📦 Cómo obtener el APK
1. Sube este proyecto a GitHub.
2. Ve a la pestaña **Actions** → workflow **Build APK**.
3. Espera unos minutos y descarga el APK desde **Artifacts** o **Releases**.

## 🌐 También funciona como web
Abre `www/index.html` en cualquier navegador.
